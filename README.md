## 💡 Project Overview

What if a comment on a livestream could control a physical device?

This project explores the connection between online audience interaction and real-world hardware.

A Python application receives viewer comments from TikTok LIVE, processes incoming messages, identifies valid commands, and translates them into actions that control an Arduino-based lighting system.

The result is a simple but interesting bridge between digital communication and physical interaction.

## ⚙️ How It Works

1. **Live Interaction:** Viewers send comments during a TikTok LIVE session.
2. **Message Reception:** The Python application receives incoming interactions.
3. **Command Processing:** Messages are evaluated to identify valid control commands.
4. **Hardware Communication:** Recognized commands are translated into hardware instructions.
5. **Physical Response:** Arduino executes the corresponding lighting action.
